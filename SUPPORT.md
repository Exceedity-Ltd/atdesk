# Getting help with atdesk

**Start here: <https://atdesk.io/support>.** It covers the common problems and
has the fastest route to a person.

## Something is broken

Run this on the computer atdesk is installed on — it checks every layer and says
which one is failing:

```
atdesk status
```

If that does not make it obvious, [open an issue](../../issues) and paste the
output. It names no file contents and no conversation text.

## Billing, cancelling, refunds

<https://atdesk.io/refunds>. You can cancel at any time and keep atdesk until the
period you have paid for ends. The model cancellation form is at the end of the
[terms](https://atdesk.io/terms#model-cancellation-form).

## Anything involving your account or personal data

Email `inbox@exceedity.com` rather than opening an issue, so it stays private.
