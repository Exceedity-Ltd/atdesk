# atdesk

**Your live Claude Code session, on your phone.**

atdesk attaches to the Claude Code session already open in VS Code on your own
computer. Read it, type into it, answer approvals, and see how much context is
left — from your iPhone, from anywhere.

- **Website and pricing** — <https://atdesk.io>
- **Install it** — <https://marketplace.visualstudio.com/items?itemName=exceedity.atdesk>
- **Support** — <https://atdesk.io/support>

£8/month including VAT · 14 days free · a card is required to start the trial.
Needs an iPhone; the computer runs macOS or Windows.

## What this repository is

This is the **public issue tracker and changelog** for atdesk. The product's
source is not here — atdesk is proprietary, and the repository exists so that
buyers have somewhere to report a problem and read what changed.

If something is wrong, [open an issue](../../issues). If it concerns your
account, billing or anything with personal data in it, please use
<https://atdesk.io/support> instead so it does not end up in public.

## Security

Please do not open a public issue for a security problem. Email
`inbox@exceedity.com` and say it is security-related.
